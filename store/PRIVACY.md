# Privacy policy - AIUB Slide Downloader

_Host this text on a public page (for example GitHub Pages) and paste its link in the Web Store "Privacy" tab._

**What the extension handles:** the names of your courses and course files on portal.aiub.edu and your AIUB Teams SharePoint sites, and a list of files it already saved (name, folder, size/date marker).

**Where it is kept:** only in your browser (`chrome.storage.local`, and the folder you chose is remembered in the browser's storage for portal.aiub.edu) and in your AIUB folder. The extension reads and writes only inside the AIUB folder you chose. Nothing is sent to the developer or to any third party. There is no analytics, advertising or tracking.

**Folder access:** Chrome gives the permission to edit your AIUB folder to the portal page (portal.aiub.edu), where the extension's panel runs. The extension only reads and writes inside that folder, and never saves program files (.exe, .bat, .msi …) there. You can take the permission back any time: the icon left of the address bar on the portal → Site settings → File editing.

**Report problem button:** only when you press it, a GitHub issue page opens with technical details (extension version, page address path, number of course links found). No names, course titles or personal data are included, and nothing is sent until you submit the issue yourself.

**Network requests:** only to portal.aiub.edu and aiubedu60714.sharepoint.com, using your own existing sign-in, to list and download your files.

**Sharing or selling data:** never.

**Remove your data:** remove the extension, or clear its data in chrome://extensions. Downloaded files stay in your folder until you delete them.
